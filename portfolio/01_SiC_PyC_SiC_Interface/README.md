# SiC/PyC/SiC Interface Mechanics and Irradiation

## Engineering Question
How do interfacial structure, irradiation-induced defects, and local carbon-layer evolution influence adhesion, debonding, and mechanical integrity in SiC/PyC/SiC systems?

## My Contribution
Developed atomistic workflows for planar SiC/PyC/SiC interfaces, structural relaxation, controlled debonding, irradiation-damage simulations, and post-processing of interfacial morphology and defect evolution.

## Methods
- Molecular dynamics using LAMMPS
- Interface construction and relaxation
- Controlled traction/debonding simulations
- Primary knock-on atom irradiation simulations
- Defect and contact analysis
- OVITO visualization and Python post-processing

## Engineering Outputs
- Traction-separation response
- Interfacial adhesion trends
- Damage and defect morphology
- Layer-resolved interfacial evolution
- Irradiation-induced changes in interface stability
