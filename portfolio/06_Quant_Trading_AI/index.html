Quant Trading AI

Independent Python project for quantitative market analysis, strategy backtesting, interactive visualization, and planned machine-learning research.

← Back to portfolio

Project Scope

This independent software project explores reproducible quantitative-finance workflows using Python, with an emphasis on data validation, backtesting discipline, time-series analysis, automated testing, and later machine-learning integration.

Current Capabilities

  • Historical daily market-data acquisition and validation
  • Daily and log-return calculations
  • 20-day and 50-day moving averages
  • Rolling annualized volatility
  • Long-only moving-average crossover strategy
  • One-day signal shifting to reduce look-ahead bias
  • Transaction-cost modeling
  • Strategy versus buy-and-hold equity curves
  • Total return, maximum drawdown, Sharpe ratio, active-day win rate, and position-change statistics
  • Interactive Streamlit dashboard
  • Automated GitHub Actions testing and Python checks

Development Roadmap

  • Richer strategy families and parameter-sensitivity analysis
  • CAGR and trade-level statistics
  • Walk-forward and strict time-series validation
  • Feature engineering and machine-learning models
  • Paper-trading integration after out-of-sample validation
  • Possible production web/SaaS architecture
