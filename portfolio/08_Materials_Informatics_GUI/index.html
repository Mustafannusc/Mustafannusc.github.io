Materials Informatics GUI: XRD and Mechanical Property Prediction for HEA/RMPEA

Graphical research tools for composition-driven crystal-structure analysis, simulated X-ray diffraction, and mechanical-property estimation in high-entropy and refractory multi-principal-element alloys.

← Back to Research Portfolio
Project objective: translate composition-based materials calculations into accessible graphical user interfaces that help researchers move from alloy composition to structural fingerprints, XRD patterns, mechanical descriptors, and candidate screening.

Two Connected Capabilities

Composition-Driven XRD Tool

A GUI workflow for entering alloy composition, constructing or reading the corresponding crystal model, and generating simulated X-ray diffraction patterns for structural interpretation and comparison.

Mechanical Property Tool

A composition-based workflow for computing or estimating mechanical and elastic descriptors for HEA/RMPEA candidate alloys using the equations, datasets, and models implemented in the project code.

Research Workflow

1. Composition input: define the elemental makeup of a HEA or RMPEA candidate.
2. Structural representation: connect composition to a crystal or atomistic representation suitable for diffraction analysis.
3. XRD calculation: generate a simulated diffraction pattern and structural fingerprint for candidate comparison.
4. Mechanical descriptors: evaluate the mechanical-property quantities supported by the implemented code.
5. GUI-based screening: present results in an interactive format that can support rapid comparison across alloy compositions.

Why This Project Matters

This work demonstrates the integration of computational materials science, Python-based analysis, visualization, and user-interface development. Instead of leaving the workflow as separate scripts, the project packages materials calculations into a research-facing tool that can support alloy screening and communicate results to users who may not work directly with the underlying code.
