ARMOR Materials Informatics GUI

Graphical user interface developed for materials-informatics workflows. The interface demonstrates the translation of composition-based materials calculations into an accessible research tool. The project includes workflows for composition-driven XRD analysis and mechanical-property calculations for high-entropy and refractory multi-principal-element alloy systems. Additional code-derived figures will be added as they are documented for public release.
